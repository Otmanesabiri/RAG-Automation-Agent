# MCP server

`scripts/mcp_server.py` exposes the document search of a running RAG Automation Agent API to MCP clients (Claude Desktop, Claude Code, other assistants). It is a thin client of the REST API: authentication, roles, tenant isolation and rate limits of the API apply unchanged.

## Tools

| Tool | Calls | Notes |
|------|-------|-------|
| `search_documents(query, top_k=5, search_mode="hybrid")` | `POST /search` | Passages with source, section, document_id (no LLM call) |
| `ask_documents(question)` | `POST /query` | Answer generated by the API, with sources |
| `get_document(document_id)` | `GET /documents/{id}` | Full text |
| `list_documents(size=20)` | `GET /documents` | Indexed documents |
| `ingest_url(url)` | `POST /ingest` | Needs the `editor` role; URLs must be public (SSRF protection) |

API errors are returned to the client as tool errors with the API's message.

## Setup

On the machine running the MCP client:

```bash
pip install mcp requests        # or: pip install -r requirements-extras.txt
```

Settings (environment variables):

| Variable | Default | Purpose |
|----------|---------|---------|
| `RAG_API_URL` | `http://localhost:8000` | Base URL of the API |
| `RAG_API_KEY` | | API key (`X-API-Key`) |
| `RAG_API_TOKEN` | | JWT, used instead of the key when set |
| `MCP_TRANSPORT` | `stdio` | `stdio` or `streamable-http` |

### Claude Code

```bash
claude mcp add rag-agent \
  -e RAG_API_URL=https://rag.example.com -e RAG_API_KEY=<key> \
  -- python /path/to/RAG-Automation-Agent/scripts/mcp_server.py
```

### Claude Desktop

In `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "rag-agent": {
      "command": "python",
      "args": ["/path/to/RAG-Automation-Agent/scripts/mcp_server.py"],
      "env": {"RAG_API_URL": "https://rag.example.com", "RAG_API_KEY": "<key>"}
    }
  }
}
```

Prefer a dedicated API key with the `reader` role (see `API_KEY_SCOPES`) unless the assistant should be able to ingest URLs.
